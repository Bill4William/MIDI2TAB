MIDI2TAB

Convert MIDI files to guitar and bass tablature

v1.0.0

MIDI2TAB is a desktop application that reads standard .mid / .midi files and converts the note data into ASCII tablature, formatted for any fretted string instrument. The output can be viewed on screen, saved as a plain-text file, exported to PDF, or sent directly to a printer.

FeatureWhat it does
MIDI parsingReads tempo, time signature, and key signature automatically from the file
Custom tuningsSet any open-string note (C0–B7) for each string individually via dropdown
String countSupports 1 to 12 strings — guitar, bass, ukulele, or anything in between
PresetsBuilt-in tunings for guitar, bass, and ukulele; save your own named presets
Song metadataBPM and key auto-populated from the MIDI file; you can fill in song name and artist
Silent compressionEmpty measures are replaced with a "Silent for N Measures" annotation instead of blank dashes
Page-safe outputTab is automatically reformatted to fit 8.5×11" paper with 0.5" margins — no cutoff
ExportSave as .txt, save as .pdf, or print directly from the app

Installation

Windows installer (recommended)

  1. Run MIDI2TAB_Setup_v1.0.0.exe.
  2. Follow the setup wizard. No administrator rights are required.
  3. Optionally tick Create desktop shortcut.
  4. Click Finish — the app will launch automatically.

macOS disk image

  1. Open MIDI2TAB_v1.0.0.dmg.
  2. Drag MIDI2TAB.app into the Applications folder shown in the window.
  3. Launch the app from Applications or Spotlight.
On first launch macOS may show a security warning because the app is not from the App Store. Go to System Settings → Privacy & Security and click Open Anyway.

Running from source

Requires Python 3.9 or later:

pip install mido reportlab Pillow customtkinter
python main.py

System requirements

  • Windows 10 / 11 (64-bit) or macOS 11+
  • ~120 MB disk space
  • No internet connection required

Quick Start

  1. Click the … button next to MIDI File and open a .mid or .midi file.
  2. BPM and key are filled in automatically. Optionally type a song name and artist.
  3. Choose an instrument preset from the Preset dropdown, or set strings and tuning manually.
  4. Click Generate Tab.
  5. The tablature appears in the right panel. Use Save PDF, Save Text, or Print to export it.
The tab displayed on screen uses your chosen Measures per line setting. When you save or print, MIDI2TAB automatically reformats the tab to fit the page — you don't need to adjust anything.

MIDI File

Click the … button to open a file browser and select a .mid or .midi file. The filename appears in the panel once loaded.

You can also use File → Open MIDI… from the menu bar or press Ctrl+O.

MIDI2TAB reads note data from all non-percussion tracks by default. Percussion (MIDI channel 10) is always skipped. Use the MIDI channel option to restrict input to a single channel.

Song Info

The Song Info section adds a header line to the top of the generated tab.

FieldSourceExample output
SongYou type itSmoke on the Water
ArtistYou type itDeep Purple
BPMAuto from MIDI tempo; editable120bpm
KeyAuto from MIDI key signature; editable dropdownKey of Gm

Only fields that contain a value appear in the header. If all four are filled in, the header looks like: 

Smoke on the Water, Deep Purple, 120bpm, Key of Gm

The BPM and Key fields are cleared and re-populated each time you open a new MIDI file. Song and Artist are left as-is so you can re-generate without re-typing them.

Not all MIDI files include a key signature. If the Key field stays blank after loading, simply type the key yourself or leave it empty.

Saving a custom preset

  1. Set the string count and tuning you want to save.
  2. Click Save Preset….
  3. Enter a name and click OK.

Your preset appears in the dropdown immediately and is stored in %APPDATA%\MIDI2TAB\user_presets.json so it persists across sessions and app updates.

Deleting a preset

Select your preset from the dropdown, then click Delete. Built-in presets cannot be deleted.

Selecting a preset automatically updates the string count and all tuning dropdowns. Changing any string or tuning manually switches the preset selector to Custom.

Strings & Tuning

Number of strings

Use the − and + buttons to set the string count from 1 to 12. The tuning row list updates instantly.

Tuning dropdowns

Strings are listed high → low (String 1 is the highest- pitched string; the last string is the lowest). Each dropdown covers C0 through B7 — the full practical range of fretted instruments.

The fret placement algorithm uses your tuning to find the most hand-position- efficient way to play each note, keeping frets between 0 (open string) and 24. Notes that cannot be played on any string within this range are skipped.

If many notes are being skipped, the MIDI file's pitch range may not match your tuning. Try shifting the tuning up or down by an octave, or switch to a different preset.

Options

OptionDefaultDescription
Beats per measure 4 Sets the time signature denominator for the tab grid (usually 4 for 4/4 time). If the MIDI is in 3/4, set this to 3.
Measures per line 4 How many measures appear in each line of the on-screen tab. Saves and prints always reformat to fit the page width, regardless of this setting.
MIDI channel All Restrict note input to a single MIDI channel (0–15). Useful when a file contains multiple instruments on separate channels.

Tab Display

After clicking Generate Tab, the tablature appears in the main panel in monospace font. Each system (set of string rows) represents one line of music.

The display is scrollable both vertically and horizontally. Use your mouse wheel to scroll vertically, or the scrollbar at the bottom for horizontal scrolling.

The on-screen display uses the Measures per line setting from the Options panel. PDF and text exports are automatically reformatted to fit the page — they may show a different number of measures per line.

Save as Text

Click Save Text (or File → Save as Text… / Ctrl+S) to save the tab as a plain .txt file.

The text file is formatted to fit within 90 characters per line (equivalent to 10 pt Courier on 8.5×11" paper with 0.5" margins), so it prints cleanly from any text editor.

Save as PDF

Click Save PDF (or File → Save as PDF… / Ctrl+Shift+S) to export the tab as a .pdf file.

MIDI2TAB automatically:

  • Fits the tab to 8.5 × 11" paper with 0.5" margins
  • Chooses the largest font size (up to 9 pt) where every line still fits
  • Adds page breaks as needed for long songs
  • Uses the Song Name as the PDF document title if one is entered

Print

Click Print (or File → Print… / Ctrl+P) to send the tab directly to your default printer.

MIDI2TAB generates a temporary PDF and sends it to the system print dialog. If the automatic print dialog does not open, the PDF will open in your default PDF viewer instead — use that application's print function.

Reading the Tab

Basic layout

Each system shows all strings simultaneously, with the highest string at the top and the lowest at the bottom: 

E5|--0---------5--------|--3-----|
B4|-----3-----------3---|--------|
G4|--------2------------|--0-----|
D4|---------------------|--------|
A3|---------------------|--------|
E3|---------------------|--------|

The label on the left of each row is the open-string note. Numbers in the row represent fret numbers (0 = open string, 12 = 12th fret, etc.). Dashes represent silence or held notes.

Header

If Song Info fields are filled in, a header appears above the first system: 

My Song, Artist Name, 120bpm, Key of Am
6 String Guitar | Standard | EADGBE

The second line shows the instrument name, preset tuning name, and all open-string notes listed from low to high.

Silent sections

Consecutive empty measures (no notes) are collapsed into a single annotation line rather than showing rows of dashes: 

E5|--0-----|
...

Silent for 8 Measures

E5|--5-----|
...

Bar lines

A vertical bar (|) marks the boundary between measures. Each measure contains beats × 4 grid slots (16th-note resolution).

Two-digit frets

Fret numbers above 9 use two characters. Each grid slot is 3 characters wide, so a fret of 12 is written as 12-.

Data & Files

FileLocationContents
user_presets.json %APPDATA%\MIDI2TAB\ Your saved instrument presets. Safe to back up or copy between machines.

The application itself stores no other data. MIDI files you open are read but never modified. Generated tab text and PDFs are only saved when you explicitly click Save or Print.

Backing up presets

Copy %APPDATA%\MIDI2TAB\user_presets.json to a safe location. To restore, place the file back in the same folder before launching the app.

Uninstalling

Use Add or Remove Programs to uninstall MIDI2TAB. The uninstaller removes the application files but does not delete your presets in %APPDATA%\MIDI2TAB. Delete that folder manually if you want a completely clean removal.

Troubleshooting

No notes found after generating

  • Check the MIDI channel setting — if a specific channel is selected, switch to All.
  • Make sure the MIDI file actually contains note data on non-percussion channels. Some files contain only tempo/time signature data.

Many notes are skipped

The status bar shows how many notes were out of range. This usually means the MIDI pitch range doesn't overlap with your tuning. Try:

  • Switching to a different preset
  • Lowering the tuning by an octave (e.g., E5 → E4)
  • Checking if the MIDI is for a transposing instrument (e.g., bass guitar sounding an octave lower than written)

The tab looks wrong — chords are split across beats

MIDI files sometimes quantize chords slightly imprecisely. MIDI2TAB uses 16th-note grid quantization to group simultaneous notes. If notes that should sound together are appearing on different beats, the MIDI file's timing may be looser than 1/16th note — this is normal for recorded (non-quantized) MIDI.

BPM or Key is wrong after loading

Simply type the correct value into the BPM or Key field. The auto-populated values come directly from the MIDI file's metadata and can always be overridden.

PDF is cut off or text is too small

MIDI2TAB automatically picks the largest font that fits all lines within the page width (minimum 6 pt, maximum 9 pt). If the font looks very small, the tab lines are very long — try reducing Beats per measure to shorten each measure, or use a preset with fewer strings.

My saved presets are not appearing

Presets are stored in %APPDATA%\MIDI2TAB\user_presets.json. Check that this file exists and is valid JSON. If it was created by an older version of the app (before v1.0.0), it may be in a different location — copy its contents and re-save each preset from within the app.

The app won't launch on macOS

macOS Gatekeeper blocks apps that are not notarized with Apple. To open:

  1. Go to System Settings → Privacy & Security.
  2. Scroll down to the security section and click Open Anyway next to the MIDI2TAB message.
  3. Confirm by clicking Open in the dialog.
For any issue not listed here, run the app from source in a terminal (python main.py) to see Python error output directly.
